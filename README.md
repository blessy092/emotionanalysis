# Text Emotion Classification Using Machine Learning

## Project Overview

This project focuses on classifying emotions expressed in text comments using Natural Language Processing (NLP) and machine learning techniques.

The project compares two machine learning algorithms, Multinomial Naive Bayes and Support Vector Machine (SVM), to determine how effectively they classify emotions in text.

## Objectives

- Load and explore the text emotion dataset.
- Clean and preprocess text comments.
- Perform tokenization and stopword removal.
- Convert text into numerical features using TF-IDF.
- Train Naive Bayes and SVM classification models.
- Evaluate and compare model performance using standard classification metrics.
- Predict emotions for new text comments.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NLTK
- Scikit-learn
- Matplotlib

## Dataset

The dataset contains two columns:

- **Comment:** The text sample used as model input.
- **Emotion:** The emotion label associated with the comment.

The dataset is used to train and evaluate the emotion classification models.

## Project Workflow

1. **Data Loading:** Load the dataset into a Pandas DataFrame.
2. **Data Preprocessing:** Handle missing values and duplicates, clean text, tokenize comments, and remove selected stopwords.
3. **Feature Extraction:** Use TF-IDF Vectorization to convert text comments into numerical features.
4. **Data Splitting:** Divide the dataset into training and testing sets.
5. **Model Training:** Train Multinomial Naive Bayes and Linear SVM models.
6. **Model Evaluation:** Evaluate both models using accuracy, precision, recall, weighted F1-score, classification reports, and confusion matrices.
7. **Emotion Prediction:** Predict the emotion associated with a new text comment using a trained model.

## Machine Learning Algorithms

### 1. Multinomial Naive Bayes

A probabilistic classification algorithm commonly used for text classification tasks.

### 2. Linear Support Vector Machine (SVM)

A supervised learning algorithm that learns decision boundaries to distinguish between emotion classes.

## Evaluation Metrics

- **Accuracy:** Measures the proportion of correctly classified samples.
- **Precision:** Measures how many predictions for an emotion are correct.
- **Recall:** Measures how many actual samples of an emotion are correctly identified.
- **F1-score:** Combines precision and recall into a single metric.

The weighted F1-score is used to compare the two models while accounting for the number of samples in each emotion class.
